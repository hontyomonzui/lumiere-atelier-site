Privacy Policy

Last updated: 2026-10-18

Lumiere Atelier ("the app") is a personal desktop application used by its developer only.

Data the app accesses

With the user's permission, the app uses the Google Tasks API (scope: https://www.googleapis.com/auth/tasks) to read and update the user's own task lists and tasks, so that they can be shown and edited inside the app.

How the data is used and stored

  • Task data is used only to display and sync the user's tasks inside the app.
  • The OAuth token and a local copy of the tasks are stored only on the user's own computer. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising or analytics.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the app (Disconnect) or at https://myaccount.google.com/permissions. Disconnecting deletes the stored token.
